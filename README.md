# Digital Clock 

A simple digital clock built with **HTML, CSS and JavaScript**. The clock displays the current time in a 12-hour format with AM/PM and automatically updates every second without requiring the page to be refreshed.

## Features

* Displays the current hours, minutes, and seconds
* Uses a 12-hour time format
* Displays AM/PM
* Automatically updates every second
* Responsive and centered layout
* Custom styling and font

## Technologies Used

* **HTML** – Used to create the structure of the clock
* **CSS** – Used to style and center the clock
* **JavaScript** – Used to retrieve and update the current time
